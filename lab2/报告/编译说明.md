# 报告源文件与编译

主文件为`实验报告.tex`，直接修改中文正文即可。图片相对引用`../UML`和`../UI界面`，请一起保留目录。源文件使用UTF-8、XeLaTeX、ctex与Microsoft YaHei字体，连续编译两遍更新目录。PDF没有页眉页脚。

在本目录执行：

```powershell
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build 实验报告.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build 实验报告.tex
Copy-Item -LiteralPath build/实验报告.pdf -Destination 实验报告.pdf
```

运行前创建build目录。若用其他系统，调整ctex的fontset和中文字体。`工具/整理设计与报告.py`可按结构化设计材料重建全文，重新运行会覆盖手工编辑过的tex；人工修改后优先直接编译，保留Git差异。重新导出图片和编译后，再运行打包工具重建ZIP。
